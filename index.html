Uso sin conexión

Qué ocurre con tus datos

Los archivos se leen con FileReader y se procesan en el navegador. No hay llamadas de red con el contenido de las facturas. Puedes comprobarlo abriendo la pestaña Red de las herramientas de desarrollo.

Las dos bibliotecas

La app usa pdf.js para abrir PDF y Tesseract.js para el OCR. En la primera carga se descargan desde una CDN y el navegador las cachea. Para que funcione con el equipo desconectado hay que dejarlas junto al HTML.

Montaje sin conexión

  1. Crea una carpeta y pon dentro este archivo HTML.
  2. Descarga pdf.min.js y pdf.worker.min.js de pdf.js y déjalos al lado.
  3. Descarga tesseract.min.js, worker.min.js y la carpeta del núcleo tesseract.js-core.
  4. Descarga los idiomas que uses de tessdata_fast: spa.traineddata.gz, eng.traineddata.gz. Ponlos en una carpeta tessdata.
  5. Edita las etiquetas <script src> del final del HTML para apuntar a los archivos locales.
  6. En «Rutas del motor OCR» escribe ./tessdata, ./tesseract-core/ y ./worker.min.js.

Cómo abrirlo

Abre el HTML con doble clic. Si el navegador bloquea los workers por el origen file://, levanta un servidor estático en la propia máquina: python -m http.server 8000 y entra en http://localhost:8000. Sigue siendo local.

Precisión

Un PDF con capa de texto se lee perfecto y sin OCR. Un escaneo a 300 ppp en blanco y negro y recto da resultados muy superiores a una foto de móvil. Revisa siempre TARIC, masa y base imponible antes de declarar: el panel de verificación muestra el texto original de cada documento.
